CrownArena — Automated PvP Event

CrownArena runs a complete, automatic PvP event on your Paper server. At the scheduled time every player gets an invitation; those who accept are moved into a private lobby and a rotating arena world with a separate inventory and the exact same kit, and they fight until the event ends. The rest of the server keeps running normally and sees the global kill feed, popped totems, streaks and the scoreboard.

Naming: this project is CrownArena. In game the command is /evento, the jar is EventoPvP-1.3.0.jar and the data folder is plugins/EventoPvP/. Same plugin, one name on Modrinth and another one inside the server.

Highlights

  • 🗓️ Automatic schedule — every other day by default, with a time per weekday; also daily,

weekly or a single time. Global reminders 30/10/5/1 min before, plus manual start.

  • 💬 One-click native invitation — the "Do you want to join?" dialog, a clickable message

and /evento aceptar.

  • 🎒 Separate inventory — inventory, armor, offhand, XP, health, hunger, effects, gamemode

and position are saved on disk and restored at the end (also after a disconnect or a crash).

  • ⚖️ Perfectly fair fight — the same configurable kit for everyone, full refill on respawn,

no drops, no XP loss, instant respawn and short spawn protection that is lost on attack.

  • 🛠️ Arenas repair themselves — every block the fight changes (placed, broken, web, water,

lava, fire) is stored and restored when the event ends, even if the server shuts down mid-fight.

  • 🌍 Arenas on their own worlds — lobby + 5 arenas, each in its own world, several spawns

each and automatic rotation every X minutes with a warning.

  • 📊 Live feedback — kill with the weapon used, popped totem, first blood, streaks,

streak-breaker, sidebar (time, arena, kills, deaths, streak, top 3) and a time boss bar.

  • 🎮 Bedrock ready — transparent sidebar on Geyser, resource pack included in the jar.

How the event runs

  1. Global announcements 30, 10, 5 and 1 minute before the start.
  2. A 10-second countdown with title and sound, then the native invitation appears.
  3. Players who accept have their state saved and are moved to the waiting lobby.
  4. A final 5-second countdown drops everyone into the arena at the same time.
  5. The fight runs with progressive mob waves; arenas rotate automatically.
  6. End: ranking, winner title, fireworks, console rewards, full inventory restore and the

arena returned to its original state.

Non-participants (and non-admins) cannot enter the lobby or the arenas, so the event never disturbs the rest of your server.

Installation (2 minutes)

  1. Copy EventoPvP-1.3.0.jar into plugins/ and restart. The plugin creates config.yml and

messages.yml.

  1. Maps (optional): download CrownArena-Maps-1.3.0.zip

and unzip it into plugins/EventoPvP/world-templates/ so the six .zip maps end up there, then restart (or run /evento instalar). Without maps the plugin creates empty worlds; you can also drop your own maps there under the same names (evento_lobby, evento_arena_1 … evento_arena_5).

  1. Set the schedule (schedule.first-date, schedule.every-days, schedule.times), the kit and

the rewards in config.yml, then /evento recargar.

  1. Check the next event with /evento proximo and test it with 2 accounts using /evento iniciar.

Requirements: Paper 26.2 (Java 25). Optional: Geyser for Bedrock players.

Configuration worth knowing

  • schedule.* — start date, how many days between events and a time per weekday.
  • kit — the items every participant gets (MATERIAL:cantidad, enchantments, potions…).
  • allow-placing-blocks / allow-breaking-blocks — building rules inside the arena.
  • arena-repair (default true) — restores every changed block when the event ends.
  • staff-only-commands (default true) — inside the event only evento.admin can run commands.
  • hunger — vanilla (default; hunger drops and damage really matters) or locked.
  • world-difficulty — difficulty forced on lobby and arenas (NORMAL by default; fixes maps

that were built on Peaceful, where you regenerate and take no real damage).

  • bedrock.scoreboard-transparent — transparent sidebar on Bedrock through Geyser.
  • messages.yml — every message, title and sound, in MiniMessage.

Español

CrownArena es un plugin de evento PvP automático para servidores Paper 26.2. A la hora programada se abre una invitación a todos; quienes aceptan pasan a un lobby y arenas en mundos propios con inventario separado y el mismo kit, hasta que termina el evento. El servidor principal sigue con su vida normal y solo ve los anuncios globales de kills, tótems reventados, rachas y marcador.

Archivos: EventoPvP-1.3.0.jar es el plugin (ligero) y CrownArena-Maps-1.3.0.zip es el lobby y las 5 arenas, opcional. Descárgalo desde GitHub Releases y descomprímelo dentro de plugins/EventoPvP/world-templates/, y reinicia (o ejecuta /evento instalar). Sin mapas el plugin crea mundos vacíos, y puedes poner los tuyos con esos mismos nombres.

Cómo funciona: avisos 30/10/5/1 min antes → cuenta de 10 s → invitación nativa (o /evento aceptar) → lobby de espera → cuenta final de 5 s y todos a la vez a la arena → hordas progresivas y rotación automática de arenas → ranking, título del ganador, fuegos artificiales, recompensas por consola, devolución del inventario y reparación de la arena.

Comandos: públicos aceptar, proximo, info, top, stats, ranking; administradores (evento.admin) iniciar, detener, spawn, reparar, lobby, lista, borrar, tparena, mundo, expulsar, recargar, instalar. La carpeta de datos es plugins/EventoPvP/.
